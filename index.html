Class activities

Lecture 3: Learning from labeled examples — Iris

Train a decision tree, check its predictions on held-out flowers, and compare two tree depths. About 20 minutes; no Python experience required.

  • Open the Iris activity in Google Colab
  • Download the Iris notebook (.ipynb)

In Colab, choose Runtime → Run all to begin. To use a downloaded copy, choose File → Upload notebook.

Lecture 6: The LLM remembers nothing

Run a small LLM in Colab with no chat app around it, and see what it can answer when you do and do not send the conversation history yourself. About 15 minutes; no Python experience required.

  • Open the LLM memory activity in Google Colab
  • Download the LLM memory notebook (.ipynb)

Step 1 downloads the model (about 1.3 GB) and takes a few minutes. Run the cells one at a time so you can write your prediction before each experiment.
