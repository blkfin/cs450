Inside an AI agent — lecture notes

CS 450 · L09 · Sept 28, 2026

The answer to today's question. An agent is a goal-directed system in which a model chooses the next allowed action, a tool carries it out, the observation updates state the harness holds, and the loop stops on success, a blocker, a request for approval, or a limit. The model does not run the loop. The harness runs the loop and calls the model.

Our vocabulary

Goal.
What counts as progress and done, in the user's words. Ticket example: two seats, ≤ $60 each including fees, show me first, never buy.
Model.
The language model. Given goal + current state, it emits one thing: a tool request or a reply to the user. It remembers nothing between calls.
Harness.
The ordinary code around the model. It validates each request, runs the tool, records the result, and decides whether to call the model again.
Tool.
A function the model may request: schedule(), quote(game), calendar_add(...). Tools act on or inspect the environment.
Action / tool request.
The model's structured ask: {"name":"quote","arguments":{"game":"B"}}. Choosing this is the one thing the model does.
Observation / tool result.
What comes back: {"game":"B","all_in":57,"seats":2}. It is evidence; the model's guess is not.
State.
Everything the harness re-supplies on the next call: goal, candidates, rejections, budget used, pending approval. Drop a line of it and the model repeats a mistake.
Stopping condition.
Success with a receipt, a blocker, a needed approval, or a limit (tool-call budget). "Done" is a claim about evidence, not confidence.

Cycle vs. turn

Loop cycle — the small unit

One model decision and what follows it. If the decision is a tool request, the harness runs the tool, records the result, updates state, and the loop goes around again. If the decision is a reply to the user, there is no tool call and the turn ends.

Count cycles by counting model decisions. Most cycles carry one tool call; a cycle may carry several.

Agent turn — the big unit

Everything from one user prompt until the agent stops: it reports, asks a question, or asks for approval. One turn holds as many cycles as the harness allows.

Count turns by counting user prompts. Budgets ("at most 6 tool calls"), approval gates, and the four stopping conditions all live at the turn boundary.
