Lectures

Id Week Lecture Key ideas
L01 1 AI right now: capability, work, and judgment Survey evidence about AI use and jobs; capability vs. reliability; forecasts and how they age; how employers describe changing tasks
L02 1 Rules, examples, and learning Definitions of intelligence; supplied rules vs. rules formed from examples; supervised learning; accuracy needs the cases attached
L03 2 ML foundations: learning a pattern that works on new cases Model, examples, training vs. use; learning the pattern, not the quirks; held-out checks; rewards; keeping claims within the evidence
L05 3 How does generative AI produce a response? Classifier vs. generator; tokens; next-token prediction repeated; sampling and temperature; plausible is not true; names, numbers, and citations
L06 3 From an LLM to chat context Parameters fixed during use; the chat harness; context; roles and hidden system instructions; why a chat "remembers"
L09 5 Inside an AI agent Goal, actions, feedback; the agent loop and state; when an agent is worth it; deterministic shell; autonomy as a dial; done is a claim about evidence
L09-NOTES 5 Agent cycles, turns, tools, and state Vocabulary; cycle vs. turn; reading a trace
L10 5 Build something real with an agent Tool calls; cycles inside a turn; capabilities and permissions; who did which part; who pays for the computing. Skip the setup slides.
L11 6 What are you using? The AI stack (lab, model, host, product, agent); model ladders; open weights vs. API-only; cost per request vs. per task; benchmarks; Pareto frontier
