CS 450: Get OpenCode working, step by step

Wednesday, October 21, 2026. Today's goal: OpenCode running on your account, and one small checked task done with it. Your instructor leads the steps from the front. Go at the room's pace, and don't skip ahead.

How to use this sheet
Every step has three parts: Type (exactly this), You should see (something like this), and If not (which fix to use, at the back of the sheet).
Your key is yours. Never paste it into a chat, a screenshot or a message, and never type it where others can see it. Nobody else types it or reads it out: not your neighbour, not an AI tool.
Stuck? Find your fix number. Not listed? Raise your hand. Working already? Help your neighbour.

Step 0: Did you set this up before? Check first (everyone, 3 minutes)

Don't redo anything yet. Redoing it can overwrite a setup that already works.

0.3 agate only: Monday's setup. Monday's handout may have left a key line in .bashrc. Check without showing anything (this prints a number of matching lines, never the key):

grep -c DEEPTHOUGHT_API_KEY ~/.bashrc

You should see

If 1 or more: lock the file so other agate users can't read it. It prints nothing:

Then check whether your settings file is Monday's handout file. Again this prints a number only:

… No such file or directory      (no file: go on)

Only if it printed 1, move it aside. This line refuses to overwrite an earlier backup:

[ -e ~/.config/opencode/opencode-monday.json ] && echo "backup already exists: ask your instructor" || mv ~/.config/opencode/opencode.json ~/.config/opencode/opencode-monday.json

It prints nothing when it worked. Then start Route A at step A3. Never open .bashrc on the projector, and never echo the key.

Route A: agate, step by step

Open Terminal (Mac: Cmd+Space, type Terminal) or PowerShell (Windows: Start, type PowerShell).

A1. Connect

Type, with your own UNH username before the @ (same on Mac and Windows):

ssh your-unh-username@agate.cs.unh.edu

You should see (first time only)

The authenticity of host 'agate.cs.unh.edu (…)' can't be established.
…
Are you sure you want to continue connecting (yes/no/[fingerprint])?

Type yes and press Enter. If not: Connection timed out → F4.

A2. Password

You should see

your-unh-username@agate.cs.unh.edu's password:

Type your UNH password. Nothing appears while you type. That's normal. Press Enter.

You should see a prompt like

your-unh-username@agate:~$

If not: Permission denied → F1. Password won't take → F2. Not on the list → F3.

✔ Checkpoint A: your screen shows your-unh-username@agate:~$. Neighbour checks: ____

A3. Is OpenCode installed?

opencode --version

You should see a number starting with 1, like

1.19.3

Got a number starting with 1? Skip to A5. opencode: command not found? Do A4. A number starting with 0 or 2 → F9.

A4. Install OpenCode (type one line at a time, Enter after each)

npm config set prefix ~/.npm-global
echo 'export PATH="$HOME/.npm-global/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
npm install -g opencode-ai@1

You should see: the first three lines print nothing. The last one ends with a line like

added … packages in …s

Now check again:

opencode --version
1.19.3

If not: command not found → F5. EACCES → F6.

✔ Checkpoint B: opencode --version prints 1.something. Neighbour checks: ____

A5. Get the course setup helper

curl -O https://blkfin.github.io/cs450/setup/opencode/setup-key.py
ls setup-key.py

You should see (after a small download table)

setup-key.py

If not: No such file or directory → retype the curl line exactly; it is case-sensitive.

A6. Prepare the settings

python3 setup-key.py prepare

You should see

Course configuration ready. No key was read or displayed.

If not: Existing OpenCode configuration differs → F12. An alternate OpenCode configuration exists → F13.

Write your check first. Count by hand before the AI does. Count each word in the list as a whole word only, ignoring capital letters and punctuation.

Words: exceptional, excellent, leader, lead, warm, kind, helpful, skills

Jordan has excellent writing skills and strong research skills. In group projects, Jordan takes the lead and keeps the team on track." Then write count.py that counts how many times each of these words appears in letter.txt as a whole word, ignoring capital letters and punctuation: exceptional, excellent, leader, lead, warm, kind, helpful, skills.
