CS 450 L13: Setup checklist and barrier swap

Monday, October 19, 2026

Handout 1: Get OpenCode talking to Deep Thought (minutes 10–30)

Rule for today: when you're stuck, paste the exact error into an AI tool first, then try its fix, then check whether it worked. Then raise your hand.
Before you paste anything, delete any key or password from it.

  1. Log in to agate. Same command on Windows and Mac:

    ssh your-unh-username@agate.cs.unh.edu

    First time? Type yes when it asks about the host.

  2. Password. Nothing shows on screen while you type. That's normal. Type it and press Enter. Never type it anywhere others can see it.

  3. OpenCode installed? Run opencode --version. If you get "command not found":

    npm config set prefix ~/.npm-global
echo 'export PATH="$HOME/.npm-global/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
npm install -g opencode-ai
opencode --version

  4. Your Deep Thought key. Open your settings file in the editor:

    nano ~/.bashrc

    Use the arrow keys to go to the very bottom, then type one new line:

    export DEEPTHOUGHT_API_KEY=<your key>

    Save with Ctrl+O, then Enter. Leave with Ctrl+X. Then run source ~/.bashrc.

    Check that the key is there without showing it:

    [ -n "$DEEPTHOUGHT_API_KEY" ] && echo "key is set" || echo "key is missing"

    "key is missing" means OpenCode will fail without telling you why. Never echo the key itself: it shows on screen, and on the projector.

  5. Point OpenCode at Deep Thought. Make the folder, then open a new file:

    mkdir -p ~/.config/opencode
nano ~/.config/opencode/opencode.json

    Paste everything in the box below (right-click or Ctrl+Shift+V in most terminals), save with Ctrl+O, Enter, and leave with Ctrl+X. Your key does not go in this file; it reads the key from step 4.

    {
  "$schema": "https://opencode.ai/config.json",
  "enabled_providers": ["deepthought"],
  "model": "deepthought/ets:aws:us.anthropic.claude-sonnet-4-6",
  "provider": {
    "deepthought": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "DeepThought",
      "options": {
        "baseURL": "https://dtcontroller.sr.unh.edu:4242/openai/v1",
        "apiKey": "{env:DEEPTHOUGHT_API_KEY}"
      },
      "models": {
        "ets:aws:us.anthropic.claude-sonnet-4-6": {
          "name": "DeepThought Claude Sonnet 4.6",
          "tool_call": true,
          "limit": { "context": 200000, "output": 8192 }
        }
      }
    }
  }
}

  6. Test it. mkdir l13-test && cd l13-test && opencode. Ask it to create and run hello.py. Done when the file exists and ran. A chat reply alone doesn't count.

Minute 30: stop, wherever you are. Not done? The CS tutoring center (second floor, about 2–6 PM, Mon–Fri) or your instructor's office hours (Mon and Wed 9–11).

Did the AI's fix work the first time? Keep a tally: ___ fixes tried, ___ worked.

Handout 2: Barrier swap (minutes 30–47)

Use any chat AI you already use. You don't need today's setup to work.

  1. Missed Friday? Write your card now (2 minutes):
    "I want to ______. What's really stopping me is ______."
  2. Write your check first. On the back: "I'd try it if ______." (Example: "I could start it this week, in under 30 minutes, for free.")
  3. Swap cards. Your neighbor opens a fresh chat, pastes only your card line, and asks for one way past the barrier.
  4. You judge it against your own check: would try or nope.
  5. If there's time: add two sentences from Friday's interview. Your neighbor reruns it in a new fresh chat. Judge it again. Did one change make the difference?

Share only what you're comfortable sharing. You decide how much context to give.
