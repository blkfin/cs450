CS 450: Build a public web page with a real AI agent

Wednesday, September 30, 2026

What you're doing today

On Monday you learned what an agent is: a model that requests actions, and software that checks and carries them out with tools. Today you'll use a real one. Cursor's agent will run on agate, write a web page, and put it on the public internet. You give it a result, boundaries, and a way to check its work.

Before you start

  • Log in to agate from your terminal, the same way you did before.
  • Sign up for a free Cursor account at cursor.com. The free plan is called Hobby, and it doesn't need a credit card.

Step 1: Install Cursor's agent (one command)

Copy and paste this into your agate terminal:

curl https://cursor.com/install -fsS | bash

When the installer finishes, it may ask you to run one more line to update your path. If it does, run it. If you're not sure, close your terminal, log in to agate again, and continue.

Step 2: Log in

agate has no web browser, so ask Cursor to print a login link instead:

NO_OPEN_BROWSER=1 agent login

Copy the link it prints, open it in the web browser on your laptop, and sign in to Cursor. Then go back to your terminal. It should say you're logged in.

Step 3: Start the agent

agent

Three rules

  1. Your pages are public. Don't put your full name, photo, student ID, phone number or anything else personal on them.
  2. Your agent requests are limited. The free plan gives a limited number of requests each month, and Cursor doesn't publish the exact number. Every prompt you send uses some of it. Today should take 2–4 prompts.
  3. Read before you approve. Some actions may run automatically. If the agent asks to run a command and you don't understand it, ask your neighbor or raise your hand before you say yes.

Step 4: Hello world, together

We'll do this one as a class. Paste this prompt:

Create a page that displays “Hello, CS 450!” at ~/public_html/cs450/index.html. Use HTML and CSS; install no software. Keep my other files unchanged. If the web server cannot read the page, explain the permission change you propose before making it. Tell me the page's public address so I can open it and check it.

Watch what happens. The agent will look at your folders, decide on a step, and may ask your permission before it runs a command. That's Monday's lesson happening on screen: the model requests an action; software checks and runs it. Some actions run automatically and others wait for you. Read what it wants to run before you say yes.

Then open this address in your laptop's browser:

https://www.cs.unh.edu/~your-agate-username/cs450/

If your page loads, you've checked that it was published. Also check that it displays what you asked for.

Step 5: Make your own page (this is today's participation)

Now make a second page on your own. Start from this prompt and fill in the brackets:

Create a new page at ~/public_html/cs450/l10.html. Start from my hello page. Give it [a dark background and large headings, or your own design choice]. Add a short section about [a public topic I choose]. Leave index.html unchanged. Use only HTML and CSS; install nothing. Make sure the web server can read it, then tell me the public address.

Test the result. If something is wrong, tell the agent: “When I ___, I expected ___, but ___.” Then open your page:

https://www.cs.unh.edu/~your-agate-username/cs450/l10.html

Submit that URL on Canvas. You get credit if it loads and it's different from your hello world page. Your taste isn't being graded.

If something goes wrong

What you seeWhat to do
agent: command not foundClose your terminal, log in to agate again, and try once more. If that doesn't work, run the path line the installer printed at the end of Step 1.
The login link doesn't work, or has expiredRun the Step 2 command again to get a new link.
Your browser shows 403 ForbiddenTell the agent: "My page shows 403 Forbidden. Fix the permissions so the web server can read it."
Your browser shows 404 Not FoundCheck the username in your address (your agate login, after the ~) and the folder name cs450.
You're stuck after 5 minutesPair up with a neighbor whose page worked. Finish yours after class and submit the URL by Friday.
